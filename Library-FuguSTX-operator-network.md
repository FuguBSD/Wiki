# FuguSTX — Operator network and key delivery

Rehearses: the shared instructions, FuguTTX IAC-DEV

**A corporate proxy stops a workstation from reaching a fresh instance.**

Evidence: 2026-08-26. The operator's proxy resets SSH and plain HTTP to an IP it
cannot categorize. A presigned-URL relay through the artifacts bucket works,
because the S3 endpoint is an allowed domain.
Scope: one corporate network. A key-delivery step that assumes workstation SSH
must run from CI instead.
